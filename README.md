# 連休のお知らせ作成

理容店の3か月分の連休を自動計算し、店頭掲示用のA4縦PDFを端末内で生成するWebアプリです。HTML・CSS・JavaScriptのみで動作し、サーバー処理・データベース・外部ライブラリは不要です。

## このバックアップの対象

- Sites公開URL：https://barber-holiday-notice-2026.taumaso.chatgpt.site
- Sites公開バージョン：5
- 公開ソースコミット：`5b62d4e071d1cd1a5b0179fc2813f3cb33b97d2f`
- 確認日：2026年10月29日（日本時間）

`dist/` の全ファイルは上記公開ソースと同一です。READMEはバックアップ用に内容を更新しています。`.openai/hosting.json` は既存Sitesの識別情報と静的ファイルの配置を保持します。認証情報は含みません。

## GitHubへの保存とSitesへの公開は別操作

**GitHubへのコミット・pushはソースのバックアップであり、Sitesへの公開ではありません。** このバックアップにはGitHubからSitesへ自動公開する設定は含めていません。GitHubに保存しても、現在のSites公開内容は変更されません。

Sitesを更新するには、別途、既存Sitesプロジェクトに対象ソースを同期し、そのソースのバージョンを保存・デプロイする公開操作が必要です。新しいSitesを作らず、`.openai/hosting.json` の既存 `project_id` を維持してください。

このアプリはダーツアプリの `codex01` とは独立しています。`codex01` に変更を加える必要はありません。

## ファイル構成

- `dist/index.html`：メイン画面
- `dist/style.css`：画面とA4縦印刷のスタイル
- `dist/calendar.js`：日本時間の初期年月、休業日の自動計算
- `dist/app.js`：年月選択、手動修正、保存、プレビュー
- `dist/pdf.js`：端末内でA4縦1枚のPDFを生成
- `dist/print.js`：ブラウザ印刷と制限時の案内
- `dist/print.html`：別タブ用の印刷専用ページ
- `.openai/hosting.json`：既存Sitesの公開設定
- `tests/calendar.test.cjs`：日付計算の検証
- `tests/print.test.cjs`：印刷イベントと印刷設定の検証
- `tests/pdf.test.cjs`：PDF構造、行数、文字サイズの検証

## 操作

開始年（1900〜2200年）と月を選ぶと、年越しを含む連続3か月を表示します。各月の修正欄で日付を変更・追加・削除（1〜4日）できます。「自動計算に戻す」でその月の修正を解除します。年月と修正内容はブラウザのlocalStorageに保存されます。保存の維持はブラウザ設定やプライベートブラウズの影響を受けます。

毎月、第3月曜日から連休が始まります。1・4・10月は3日間、8月は4日間、その他は2日間です。暦計算はUTCで扱い、初期年月はAsia/Tokyoで取得します。

## PDF保存・印刷

「A4のPDFを作成」を押すと、張り紙だけのPDFを端末内で生成します。「PDFを開く・印刷する」「PDFを保存する」から利用してください。iPhoneでは開いたPDFの共有から「ファイルに保存」または「プリント」を選べます。日付を修正したらPDFを作り直してください。

PDFはA4縦1枚・300dpiの画像を含む形式です。URL・日付などのブラウザのヘッダー／フッターは含みません。2・3日間は同じ文字サイズで1行、4日間は2日ずつ2行です。3日間が1行に収まるサイズを基準に、全月共通の文字サイズを調整します。月見出しは月のみです。

従来のブラウザ印刷も残していますが、Safariの印刷ヘッダー／フッターや表示環境の制限があるため、通常は生成したPDFを利用してください。iPhone実機での保存・印刷結果は未確認です。

## ローカル確認とテスト

`dist/index.html` をブラウザで開くか、次の静的サーバーで確認できます。

```sh
python3 -m http.server 8000 --directory dist
```

Node.jsでテストを実行します。依存パッケージのインストールは不要です。

```sh
node tests/calendar.test.cjs
node tests/print.test.cjs
node tests/pdf.test.cjs
```

日付計算は1900〜2201年の全3,624か月、うるう日、年越し、日本時間の切り替わりを検証します。印刷イベント・A4縦設定、PDFの1ページ構造・行数・共通文字サイズもテストします。これらは実機Safari・プリンターでの検証を代替するものではありません。
